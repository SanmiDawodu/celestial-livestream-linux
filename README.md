# Celestial Worldwide Livestream for Linux

The official livestream player of the Celestial Church of Christ (CCC) Worldwide Community:
the live services, Studio 2 and the CCC Worldwide 24/7 channel. It is a small Electron window
around the church's web player at https://cccworldwide.net/livestream-app/.

Get it from Flathub, the Snap Store, or as a .deb / AppImage at https://ccc-worldwide.org/app/.

Run from source:

```
npm install electron@39.2.7
npx electron .
```
